SPECIFICA PARAMETRI CONFIGURABILI - LASER ROBOT APP
===================================================

Obiettivo
---------
Rendere configurabile dall'app Flutter il maggior numero possibile di comportamenti oggi presenti
nel software robot, mantenendo come default i valori attuali.

Convenzione nomi
----------------
I parametri usano nomi univoci in dot notation, ad esempio:

    motion.weld.speed_mm_s
    geometry.polyline.simple.pre_exit.dz_mm
    timing.laser_off_before_exit_s

Questa convenzione permette di:
- usare gli stessi nomi in Flutter;
- salvarli facilmente in JSON;
- distinguere chiaramente sezioni e significato;
- evitare nomi legacy poco chiari come "uscitaxd", "uscitaxu", "raggio", ecc.

Tipi usati
----------
bool        = true / false
int         = numero intero
double      = numero decimale
string      = testo
enum        = uno tra valori predefiniti
array       = lista
array<int>  = lista di interi
array<double> = lista di numeri decimali
array<posj> = lista di pose articolari robot [j1,j2,j3,j4,j5,j6]

ESEMPIO PRATICO
======================================================================

Esigenza:
    "Quando prendo il punto mi distacco di 10 mm.
     Quando finisco il cordone salgo di 5 mm.
     Voglio raggio 2 mm."

Per controrotaia semplice polilinea:

    capture.simple.retreat_dy_mm = 10

    geometry.polyline.simple.pre_exit.dz_mm = 5

    motion.polyline.pre_exit.radius_mm = 2

Nessuna modifica al file robot.
Tutto gestito dall'app Flutter.


======================================================================
NOTA FINALE
======================================================================

La configurazione ideale dovrebbe funzionare così:

    DEFAULT ROBOT
        +
    PROFILO MACCHINA
        +
    PROFILO LAVORAZIONE
        +
    OVERRIDE DELLA SINGOLA ESECUZIONE

Il risultato finale è la configurazione effettiva inviata dall'app Flutter.

In questo modo:
- i default restano quelli attuali;
- ogni parametro può essere cambiato dall'app;
- si possono creare preset diversi;
- si può differenziare piano / semplice / doppia;
- si può differenziare lineare / polilinea;
- non è necessario modificare il file robot per cambiare offset, velocità, raggi, attese o pose.
